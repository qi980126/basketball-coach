# 篮球教练实时计分软件 🏀

一个专为篮球教练设计的实时比赛计分和数据统计工具。

![预览图](预览图待添加)

## ✨ 主要功能

### 📋 球员管理
- 添加/编辑/删除球员信息
- 球衣号码、姓名、位置管理
- 快速换人功能

### 📊 实时计分
- **得分记录**：2分球、3分球、罚球（命中/不中）
- **其他数据**：篮板、助攻、抢断、盖帽、失误、犯规
- **对方得分**：快速记录对方1/2/3分
- **撤销功能**：支持50步撤销

### 📈 专业统计
- **基础统计**：得分、篮板、助攻、抢断、盖帽、失误、犯规
- **命中率**：FG%、3P%、FT%
- **高级指标**：
  - eFG% (有效命中率)
  - TS% (真实命中率)
  - USG% (使用率)
  - ORtg (进攻效率)
  - AST% (助攻率)
  - TOV% (失误率)

### ⏱️ 比赛计时
- 每节10分钟，共四节
- 开始/暂停/重置
- 下一节按钮
- 实时倒计时

### 🏟️ 球场视图
- 篮球俯视图展示
- 投篮区域分布统计
- 球员得分排行榜

### 📥 数据导出
- 一键导出Excel报表
- 包含所有球员详细数据
- 团队统计汇总

### 📝 比赛动态
- 实时记录所有比赛事件
- 显示最近15条动态
- 按类型颜色区分

## 🚀 快速开始

### 方式1：直接使用
双击 `index-standalone.html` 在浏览器中打开即可使用。

### 方式2：在线访问
部署到GitHub Pages后，通过网址或扫码访问。

## 📱 使用说明

### 比赛前
1. 点击"添加球员"输入球员信息
2. 设置球队名称

### 比赛中
1. 点击"开始计时"开始比赛
2. 点击场上球员对应的统计按钮记录数据
3. 需要换人时点击"换人"按钮
4. 误操作可点击"撤销"按钮

### 比赛结束
1. 点击"导出Excel"保存数据
2. 查看统计面板分析球员表现
